# Imitate Skill — 模仿强者对话

## 两种工作模式

### 模式A：手动指定人名（优先）

当用户指定了具体人名时，直接使用这些人名创建 agent。

**触发格式**：
- `/imitate 马斯克 库克 你认为小米汽车怎么样？`
- `/imitate 巴菲特 芒格 茅台值得投资吗？`
- `扮演马斯克和库克，回答：特斯拉的竞争优势是什么？`

**执行流程**：
1. 解析出指定的人名（取前2个）
2. 解析出用户的问题（人名之后的所有内容）
3. 并行启动 2 个 agent，分别扮演这 2 个人
4. 各自独立回答，汇总呈现

### 模式B：领域搜索

当用户只指定领域时，自动搜索该领域最强的 2 个人。

**触发格式**：
- `/imitate 投资 你怎么看当前市场？`
- `扮演投资领域的专家，帮我分析一下`

**执行流程**：
1. 解析领域关键词
2. `web_search` 搜索该领域最强的 2 个人
3. 并行启动 2 个 agent
4. 各自独立回答，汇总呈现

## 统一汇总格式

**三人对话版**（当用户想听 Claude 的解读时）：

```
## [人物A姓名] 的观点

[内容]

---

## [人物B姓名] 的观点

[内容]

---

## 💬 Claude 说人话

[以简洁直白的方式总结两人的核心分歧、共同点，给出接地气的普通人视角解读]
```

## Agent 提示词模板

```
你扮演的是 [姓名]，[背景简介]。

回答问题时：
- 站在 [姓名] 的角度和立场
- 风格：[专业严谨/犀利直接/幽默风趣/务实接地气等]
- 可以适当展现该人物的标志性观点或语气

用户的问题是：[用户的具体问题]

请用中文回答，150-300字左右。
```

## 示例

### 示例1：手动指定人名

**用户输入**：
```
/imitate 马斯克 库克 你认为小米汽车怎么样？
```

**AI 解析**：
- 人物A：马斯克
- 人物B：库克
- 问题：你认为小米汽车怎么样？

**输出**：
```
## 马斯克 的观点

[以马斯克视角回答]

---

## 库克 的观点

[以库克视角回答]
```

### 示例2：领域搜索

**用户输入**：
```
/imitate 短视频运营 如何提高口播能力？
```

**AI 解析**：
- 领域：短视频运营
- 问题：如何提高口播能力？

**输出**：
```
## [搜索到的专家A] 的观点

[内容]

---

## [搜索到的专家B] 的观点

[内容]
```

---

## 注意事项

- **手动指定优先**：如果用户输入了人名，优先使用人名，不搜索
- **搜索优先中文**：模式B下，优先搜索中文领域专家
- **Token 消耗**：并行 2 个 agent，Token 消耗约翻倍
- **观点差异**：两人独立回答，不强制辩论，可以有不同看法
