## 安装

### 方式一：复制文件

```bash
# Windows
copy imitate\SKILL.md %USERPROFILE%\.claude\skills\imitate\

# Linux/Mac
cp -r imitate/ ~/.claude/skills/
```

### 方式二：OpenClaw 用户

```bash
npx clawhub@latest install SCHAEZEL/imitate-skill
```
